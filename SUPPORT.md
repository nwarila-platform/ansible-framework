# Support

## Supported use case

This repository supports the Ansible framework itself, the roles within it, the repository automation around it, and the developer workflow needed to work on it safely and consistently.

## Out of scope

- Troubleshooting your specific infrastructure or Ansible inventory.
- Recovering failed deployments in downstream environments.
- Handling credentials or environment-specific secret management for consumers.

## When requesting help

Include:

- The command you ran (e.g., `ansible-playbook`, `ansible-lint`)
- The operating system (control node and target)
- The role and task file involved
- The exact error output
- Your Ansible and Python versions (`ansible --version`, `python3 --version`)
